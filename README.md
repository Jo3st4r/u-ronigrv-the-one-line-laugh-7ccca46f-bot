## The line

> The lift broke down with a stranger for twenty minutes, so now we send each other Christmas cards and still don't know each other's names.

20 minutes stuck, 0 names learned, 1 Christmas card a year: the
lift breaks down, two strangers bond, and the friendship outlasts
the introduction that never happened. An everyday truth — everyone
has been trapped with a stranger — with the surprise saved for the
last three words.
